# JarvOS — downloads

Installers for **JarvOS** — a local-first desktop voice assistant.

Grab the latest build from the [**Releases**](../../releases/latest) page, or from
[jarvos.app](https://jarvos.app).

| Platform | File |
|---|---|
| macOS (Apple silicon + Intel) | `.dmg` — signed and notarised |
| Windows | `.msi` |
| Linux | `.AppImage` / `.deb` |

This repository holds **only the published installers**. It carries no source
code: the application source lives in a private repository, and the binaries are
built there by CI and copied here so that downloads work without making the
source public.

Bugs and questions: <support@jarvos.app>
